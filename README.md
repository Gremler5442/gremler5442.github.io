# Escape From Shadow — GitHub Pages landing page

Static landing page built with HTML, CSS and vanilla JavaScript.

## Publish
1. Copy `index.html`, `style.css`, `script.js`, and the `assets/` folder to the root of your existing GitHub Pages repository.
2. Commit and push to the branch/folder configured in GitHub Pages.
3. Open the Pages URL after deployment finishes.

## Before publishing
- Verify the Google Play listing URL in `index.html`:
  `https://play.google.com/store/apps/details?id=com.kodask.escapefromshadow`
- Add a real Privacy Policy and contact link if you want them displayed. They are intentionally not fabricated in this draft.
- The current page uses the supplied logo and app icon. No gameplay screenshots were supplied, so the design does not pretend to show gameplay footage.
